# 数据与坐标约定

每条episode包含 `episode.json`、`samples.jsonl` 和两个相机目录。原始图像PNG可编辑复用，逐帧JSON保留真实TCP旋转向量、关节位置/速度、Robotiq原始状态、名义开口估计、目标TCP和目标开口，以及相机硬件时间、时钟域、帧号、软件接收时间、机器人时间和命令时间。

`base_T_policy` 将策略坐标转到UR基座；`tcp_T_policy_tool` 将策略工具坐标转到当前UR TCP。正向为 `policy_T_tool = inverse(base_T_policy) @ base_T_tcp @ tcp_T_policy_tool`，逆向严格复用同一变换。UR使用米与旋转向量弧度；策略观测四元数为xyzw；rotation6d为旋转矩阵前两行，与PyTorch3D约定一致。动作绝对位置3、rotation6d6、夹爪1：-1张开、+1闭合。

Robotiq原始position寄存器通过名义0..255映射到85..0mm，这是开口估计，不宣称精密间隙标定。策略的双指输入是显式的虚拟映射：完全张开对应 `[0.04,-0.04]`、闭合对应 `[0,0]`；中间按开口线性插值。真实寄存器保留在原始数据中，这两个虚拟值不能当成Panda实测关节，也不能据此声称消除了跨本体差异。

采集20Hz、机器人伺服125Hz、相机30Hz，夹爪反馈独立后台轮询。采集快照使用最近收到的各源读数，并检查接收年龄；训练沿20Hz网格选择不晚于该网格的记录。保留源时钟域，不直接相减不同硬件时钟。该实现是软件时间对齐，不是硬件触发同步。图像时间与动作时间的真实延迟可从原始记录核查。

训练action来自当次观测之后发送的目标指令，不用实际位姿替代指令。窗口以当前时刻为第二个观测，动作序列按原DP horizon10、obs2、action8对齐，首尾越界重复边界帧。相邻窗口相关，不作为独立演示计数。

数据拆分按完整演示进行，失败、不完整和评测episode不进入默认监督训练；失败素材保留供诊断。归一化保留源权重，run.json记录帧/时间约定，恢复指纹涵盖元数据、JSON和原始图像。变换、采样或图像修改后不能静默继续同一run。

学习算法与权重源代码不改。源模型依赖的Panda夹爪、末端参考点和相机关系通过这个适配显式暴露；直接迁移结果允许失败。需要重新估计归一化、改变模型输入结构或训练频率时，应另定义适配实验，而不是静默替换含义。
